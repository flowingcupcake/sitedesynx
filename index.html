Desynx Lua API Reference
FFlag Functions
desynx.getflag(name)
Returns a table with flag info: {name, type, typename, value, modified, offset}
Returns nil if flag not found.
desynx.setflag(name, value, [type])
Sets and applies flag value. Optional type: "Bool", "String", "Int"
Returns true on success, false and error message on failure.
desynx.applyflag(name)
Writes the flag value to Roblox memory. Returns true on success.
desynx.resetflag(name)
Resets flag to its original value.
desynx.listflags([pattern])
Returns array of flag names matching pattern. Empty pattern returns all flags.
Desync Functions
desynx.setdesync(enabled)
Enable/disable desync (NextGenReplicatorEnabledWrite4). Pass true to enable, false to disable.
desynx.getdesync()
Returns current desync state (boolean).
Utility Functions
desynx.isattached()
Returns: attached (bool), pid (number if attached)
desynx.notify(msg, [duration], [isError], [isSuccess])
Shows a notification. Duration defaults to 3 seconds.
desynx.sleep(ms)
Non-blocking sleep (max 30000ms). UI stays responsive.
desynx.clear()
Clears the output console.
print(...)
Standard Lua print, outputs to console.
GUI Functions
Creating Elements:
gui.window(title, x, y, w, h)
Creates a draggable window. Returns window ID.
gui.button(windowId, text, x, y, w, h, callback)
Adds button to window. Callback is global function name.
gui.label(windowId, text, x, y)
Adds text label to window.
gui.checkbox(windowId, text, x, y, callback)
Adds checkbox to window.
gui.slider(windowId, text, x, y, w, min, max, default, callback)
Adds slider to window.
gui.input(windowId, label, x, y, w, default)
Adds text input field to window.
Utility Functions:
gui.settext(id, text)
Update element text/label.
gui.setvisible(id, bool)
Show/hide element.
gui.getvalue(id)
Get value from checkbox/slider/input.
gui.destroy(id)
Remove element and its children.
gui.clear()
Remove all GUI elements.
Example Scripts 
-- Toggle blur off
desynx.setflag("FIntRobloxGuiBlurIntensity", 0, "Int")
desynx.notify("Blur disabled", 2, false, true)

-- Enable desync
desynx.setdesync(true)
local state = desynx.getdesync()
print("Desync active: " .. tostring(state))

-- List all flags matching "Blur"
local flags = desynx.listflags("Blur")
for _, name in ipairs(flags) do
  print(name)
end
